# 🎓 초등학교 생활기록부 사진 자동 크롭 프로그램

교육부 **나이스(NEIS) 학교생활기록부 사진 표준 규격(3.5cm × 4.5cm)**에 맞추어, 여러 장의 학생 사진을 **자동으로 얼굴 인식하여 완벽한 구도로 자르고 일괄 저장**해주는 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **다중 파일 일괄 추가 및 드래그 앤 드롭**
   - 수십~수백 장의 학생 사진을 한 번에 드래그하거나 [파일 선택], [폴더째 선택], 클립보드 붙여넣기(`Ctrl+V`)로 추가할 수 있습니다.
2. **인공지능 자동 얼굴 감지 & 생기부 맞춤 크롭**
   - 사진이 등록되는 즉시 얼굴의 중심과 크기를 감지하여, 나이스 규정(얼굴이 세로의 약 50~60%, 정수리 여백 12~14%, 눈높이 40%, 턱선 68%)에 맞춘 최적의 구도로 자동 크롭 영역을 잡아줍니다.
3. **실시간 미리보기 & 직관적인 수동 미세조정**
   - **위치 이동 (Pan)**: 캔버스를 마우스로 직접 잡고 드래그하여 얼굴 위치를 자유롭게 이동.
   - **확대 / 축소 (Zoom)**: 마우스 휠을 돌리거나 우측 슬라이더로 40% ~ 250% 정밀 조절.
   - **기울기 회전 & 좌우 반전**: 사진이 삐뚤어졌을 때 미세 각도 조절(-30° ~ +30°) 및 90도 회전, 좌우 반전 지원.
   - **생기부 가이드선 오버레이**: 정수리선(분홍), 눈높이선(시안), 턱선(초록), 중심선이 표시되어 규격 일치 여부를 즉시 확인 가능.
   - **원클릭 자동 리셋 (`R`)**: 수동 조정 후 언제든 초기 자동 감지 위치로 원클릭 복귀.
4. **개별 저장 및 일괄 ZIP 다운로드**
   - **개별 저장 (`Ctrl+S`)**: 현재 선택된 학생 사진을 즉시 다운로드.
   - **전체 일괄 저장 (.ZIP)**: 목록의 모든 사진을 고화질로 일괄 변환하여 하나의 ZIP 압축 파일로 패키징 다운로드 (실시간 진행률 표시).
5. **포맷 및 해상도 자유 선택**
   - **포맷**: **JPG** (품질 80%~100% 조절) 또는 **PNG** 선택 가능.
   - **나이스 표준 규격 프리셋**:
     - `나이스 표준 고화질` (413 × 531 px, 3.5×4.5cm 300DPI 권장 규격)
     - `나이스 일반 표준` (350 × 450 px, 기본 규격)
     - `인쇄용 초고화질` (700 × 900 px, 600DPI 인쇄 및 졸업앨범용)
   - **파일명 저장 규칙**: 원본명에 `_생기부` 접미사 추가, 원본명 유지, 번호순 매기기(`01_김하늘.jpg` 등) 옵션 제공.
6. **100% 로컬 오프라인 보안 (서버 전송 없음)**
   - 학생 사진은 민감한 개인정보입니다. 외부 서버로 사진이 단 1바이트도 전송되지 않으며, 사용자의 브라우저 메모리 안에서만 100% 처리되므로 인터넷 연결이 차단된 교내 폐쇄망 PC에서도 완벽하게 동작합니다.

## ⌨️ 편리한 단축키

| 단축키 | 동작 |
| :--- | :--- |
| **`←` / `PageUp`** | 이전 사진으로 이동 |
| **`→` / `PageDown`** | 다음 사진으로 이동 |
| **`Ctrl` + `S`** | 현재 사진 즉시 저장 |
| **`R`** | 현재 사진 초기 자동 맞춤 상태로 리셋 |
| **`G`** | 생기부 가이드선 켜기 / 끄기 토글 |
| **`Ctrl` + `V`** | 캡처한 이미지 클립보드 붙여넣기 |
| **마우스 휠** | 마우스 커서 위치에서 확대 / 축소 |
| **마우스 드래그** | 사진 위치 이동 |
